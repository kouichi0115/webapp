# Chromebook で使う方法（Google Apps Script 版）

インストール不要です。先生の学校Googleアカウントで一度だけ準備すれば、生徒はURLを開くだけで回答できます。

## 準備（先生が1回だけ・約5分）

1. Chromebook で https://script.google.com を開き、「新しいプロジェクト」を押す
2. 左上の「無題のプロジェクト」をクリックして「アンケート」などに名前を変更
3. **Code.gs**: 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付ける
4. **index.html**: 左の「ファイル」の「＋」→「HTML」→ 名前を `index` にして作成し、中身をすべて消して `index.html` の内容を貼り付ける
5. `Code.gs` の上のほうにある `const ADMIN_PASSWORD = 'sensei';` の `sensei` を好きなパスワードに変更
6. 保存（Ctrl + S）
7. 右上の「デプロイ」→「新しいデプロイ」→ 歯車アイコン →「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **（学校名）内の全員**
8. 「デプロイ」を押し、アクセス承認の画面が出たら自分のアカウントで「許可」する
9. 表示された「ウェブアプリのURL」（`https://script.google.com/.../exec`）をコピー

## 授業で使う

| 画面 | URL | 使う人 |
|---|---|---|
| 回答画面 | ウェブアプリのURL | 生徒（Google Classroom などでURLを配布） |
| 集計画面 | ウェブアプリのURL の末尾に `?page=admin` | 先生（プロジェクターに表示） |

- 集計画面は2秒ごとに自動更新されます
- 質問の変更・リセット・受付終了は、集計画面でパスワードを入力して操作します（一度成功すると、その端末ではパスワードが記憶されます）
- 生徒に集計画面のURLとパスワードを教えないでください
- 生徒は学校アカウントで1人1票です（選び直すと上書き）

## コードを変更したとき

「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョンを「新しいバージョン」にして「デプロイ」。URLは変わりません。
