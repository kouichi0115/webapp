# はい/いいえ アンケートアプリ

複数の端末から「はい」「いいえ」で回答し、集計用端末に数と割合をリアルタイム表示する Web アプリです。

## 起動

Node.js 18 以上が必要です（追加ライブラリ不要）。

```bash
npm start
```

起動すると、同じネットワークの端末からアクセスできる URL が表示されます。

| 画面 | URL | 用途 |
|---|---|---|
| 回答画面 | `http://<サーバーのIP>:3000/` | 各端末で「はい」「いいえ」を選択 |
| 集計画面 | `http://<サーバーのIP>:3000/admin` | はい/いいえの数・割合を表示 |

ポートを変える場合: `PORT=8080 npm start`

## 機能

- 1端末1票（ブラウザごとに識別。選び直すと回答が上書きされます）
- 集計画面は回答があるたびに自動更新（ページの再読み込み不要）
- 集計画面から質問の変更・集計リセット・受付の終了/再開
- 集計結果は `data.json` に保存され、サーバー再起動後も残ります
