# はい/いいえ アンケートアプリ

複数の端末から「はい」「いいえ」で回答し、集計用端末に数と割合をリアルタイム表示する Web アプリです。

## 起動

Node.js 18 以上が必要です（追加ライブラリ不要）。

```bash
npm start
```

起動すると、同じネットワークの端末からアクセスできる URL が表示されます。

| 画面 | URL | 用途 |
|---|---|---|
| 回答画面 | `http://<サーバーのIP>:3000/` | 各端末で「はい」「いいえ」を選択 |
| 集計画面 | `http://<サーバーのIP>:3000/admin` | はい/いいえの数・割合を表示 |

ポートを変える場合: `PORT=8080 npm start`

## 機能

- 1端末1票（ブラウザごとに識別。選び直すと回答が上書きされます）
- 集計画面は回答があるたびに自動更新（ページの再読み込み不要）
- 集計画面から質問の変更・集計リセット・受付の終了/再開
- 集計結果は `data.json` に保存され、サーバー再起動後も残ります

## かんたん起動
- Windows: `start.bat` をダブルクリック
- Mac: `start.command` をダブルクリック

初回起動時に「ネットワークへのアクセスを許可しますか」と出たら「許可」を選んでください（他の端末から接続するために必要です）。

# TOWA様のぼうけん（横スクロールアクションゲーム）

`game/index.html` をブラウザで開くだけで遊べます（インストール不要、スマホ・PC両対応）。

## 操作
| 操作 | PC | スマホ | コントローラー |
|---|---|---|---|
| 移動 | ← → (A / D) | 左下の ◀ ▶ | 左スティック / 十字キー |
| ジャンプ（長押しで高く） | Space / ↑ / Z | ジャンプ | A（PS は ×） |
| りんごを投げる | X | なげる | B / X（PS は ○ / □）、RB / RT |
| ひっさつ技を使う | S / V | ひっさつ | Y（PS は △）/ LB / LT |
| ひっさつ技をきりかえ | Q / E | 左上のゲージをタップ | RB |
| 一時停止・スタート | P / Esc | 右上の ⏸ | START |
| タイトルへ（ゲームオーバー時） | P | 右上の ⏸ | SELECT |

コントローラー（Xbox / PlayStation / Switch Pro など）は USB か Bluetooth でつなぎ、ゲーム画面でボタンを1回押すと使えるようになります。

## 遊び方
- 着地せずに続けて敵を踏むと、点数が 100→200→400→800…と2倍ずつ増える（最大 51,200 点）
- 敵は踏んでやっつける。イガグリは踏めないので、りんごを投げて倒す
- りんごを拾うと投げる弾が増える（最大99個）。ステージクリア時に持っているりんご1個につき50点のボーナス。りんごブロックを下から叩いても出る
- ジュースのびんで HP 回復。大きなジュースのびんがゴール
- ステージ（全17）: 森の小道 → りんご畑 → 木の上 → 中ボス「いばりモグラ」 → 地下のどうくつ → 夜の森 → 雪の山 → ボス「いじわるカラス」 → 雨の池 → お菓子の国 → 火山 → 海と砂浜 → おばけ屋敷 → ふしぎな工場 → 宇宙 → 雲の上 → ラスボス「くろくも大王」
- 海と砂浜: 波で水が満ちてくるので岩の上へ、カニとトゲのヤドカリ／おばけ屋敷: おばけは見ていないと近づく、消える床／ふしぎな工場: ベルトコンベアとプレス機、ロボット／宇宙: 重力が弱く高くとべる、いんせきが降る
- 倒した敵は約10秒後に元の場所で復活する
- ステージのりんごを全部取ってゴールすると、ボーナスステージへ（5種類からランダム、どれも30秒）
  - りんご天国：りんごを集める（1個100点）。全部取るとパーフェクト
  - ジュースの滝：降ってくるりんごを受け取る。金のりんご+500、どくりんごは-300。どくりんごを取らなければパーフェクト
  - のぼれ！雲のタワー：縦に長い雲のタワーをのぼる。てっぺんでパーフェクト
  - ふみふみラッシュ：とんでくる風船を踏む。20こでパーフェクト
  - たからさがし：キラキラのブロックを下からたたいて宝（りんご10個・ジュース・1UP・金のりんご）を探す。全部見つけてパーフェクト
  - パーフェクトは +5000 点
- 雨の池: 水に落ちるとミス、ハスの葉を渡る／お菓子の国: ジャムの上は足が遅くジャンプも低い／火山: 溶岩がせり上がるので高い足場へ、火の玉が跳ねる／雲の上: 風で押し戻される、かみなり雲が雷を落とす
- くろくも大王: 降りてきて息を吸っているあいだに踏むか、りんごを当てる。HPが半分になると怒って雷が2本・床がすべるようになる
- りんご畑: オレンジのキノコに乗ると大ジャンプ／どうくつ: つらら石が落ちてくる・ひびの入った足場はくずれる／雪の山: 氷の上はすべる、雪玉が転がってくる
- 敵を倒すと「ひっさつゲージ」がたまる（踏む・りんごで倒す +15、ボスに当てる +10、りんごを拾う +2）。満タンでひっさつ技が使える。技は5種類から切り替えて選ぶ
  - りんごの雨：画面内の敵をまとめて倒す。ボスに2ダメージ
  - 葉っぱトルネード：5秒間 無敵＆足が速くなり、ぶつかった敵を倒す
  - ジュースビーム：前方に画面の端までビーム。線上の敵と飛び道具を消す。ボスに3ダメージ
  - ふたばバリア：10秒間、飛び道具を消し、ダメージを1回防ぐ
  - ただいまジャンプ：大ジャンプして着地で地震。地面の敵をまとめて倒す。地中のモグラにも2ダメージ
- 中ボスを倒すと残機 +1。ゲームオーバーになっても、そのステージからコンティニューできる

## ひみつのチート
タイトル画面で次のどれかをすると、チートメニューが開きます。
- キーボード：**T → O → W → A** と順に押す
- コントローラー：**← → ← → Y**
- スマホ・マウス：**TOWA様を5回続けてタップ**

| チート | 内容 |
|---|---|
| むてき | ダメージを受けない。穴に落ちても最後に立っていた足場に戻る |
| りんご・ゲージ むげん | りんごはいつも99個、ひっさつゲージはいつも満タン |
| ざんき 99 | 残機99。ミスしても減らない |
| 空中ジャンプ | 空中で何回でもジャンプできる |
| ステージ | 好きなステージから始められる |

チートを1つでも ON にしているあいだは、ハイスコアは記録されません。
